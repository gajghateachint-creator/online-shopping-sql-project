# Online Shopping Management System (SQL)

MySQL project with 7 tables: customer, category, product, orders, order_items, invoice, payment.

## Files
- online_shopping_project.sql: table creation, sample data, and queries Q1 to Q50

## How to run
1. Install MySQL and MySQL Workbench
2. Open the .sql file in Workbench
3. Run it (Ctrl+Shift+Enter)
